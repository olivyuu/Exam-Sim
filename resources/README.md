# resources/

- `ocr-helper.swift` — source for the macOS OCR helper. `npm run build:ocr` compiles it to `ocr-helper` (that binary is gitignored).
- `lab-reference.pdf` — **optional, not in git.** Find a publicly available laboratory reference-ranges PDF, then either choose it in the app (**Choose lab values PDF**) or copy it here with this exact filename before `npm run pack`.
