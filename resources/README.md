# resources/

- `ocr-helper.swift` — source for the macOS OCR helper. `npm run build:ocr` compiles it to `ocr-helper` (that binary is gitignored).
- `lab-reference.pdf` — **optional, not in git.** If you have a laboratory values PDF you are allowed to use, copy it here with this exact filename before `npm run pack`. The app then opens it from **Lab Values**.
